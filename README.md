# Vets for Ibogaine

Website for VetsForIbogaine.org — Next.js + Supabase + Vercel.

- **Admin guide (non-technical):** `docs/ADMIN_GUIDE.md`
- **Developer notes:** `CLAUDE.md`

## Local development
```bash
cp .env.example .env.local   # fill in the Supabase URL and publishable key
npm install
npm run dev
```
Dashboard: http://localhost:3000/admin
